# Working on graceandgladness.com

Read `DESIGN.md` before changing or adding any page, and follow it.
Read `README.md` for how the site is built and published.

- Plain HTML and CSS. No build step and no frameworks.
- Shared styles live in `assets/site.css`. Use its CSS variables.
- Pages under `preview/` are unlinked drafts for review. Do not link to them from real pages.
- Commit messages and page text: plain words, short sentences, no em dashes.
